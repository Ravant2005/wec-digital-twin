# Web Research Protocol

When you need external information:
1. Use `agent-reach` to search or fetch information.
2. Rely only on authoritative sources (e.g., official documentation, peer-reviewed literature).
3. Record the source explicitly.
4. Distinguish facts derived from the source vs model reasoning.
5. Do not invent citations or present unverified claims as established facts.
