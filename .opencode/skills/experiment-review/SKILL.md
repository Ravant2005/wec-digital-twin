# Experiment Review Protocol

A task is NOT complete merely because the code executes without errors.

When reviewing an experiment:
1. **Physical Correctness**: Does the outcome align with governing physics? Are units correct?
2. **Data Provenance**: Was real data used appropriately without leakage? 
3. **Comparison**: Are the results evaluated against meaningful baselines (e.g., passive or classical control)?
4. **Metrics**: Are the metrics tied directly to the research question (e.g., captured energy, constraint violations, forecast RMSE)?
5. **Honest Claims**: State limitations and assumptions. Never invent a performance number.
